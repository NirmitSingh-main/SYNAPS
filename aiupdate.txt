--- WHY CNN + TRANSFORMER ALONE HAS NOT SOLVED QPSK/QAM16 ---
1. Loss of Constellation Topology:
   - The Conv1D operates only across 1D continuous time.
   - The Transformer attends all-to-all across 1D sequence tokens.
   - Neither model explicitly operates on the 2D (I, Q) phase space geometry where QPSK (single ring, r=1) and QAM16 (3 concentric rings, r=sqrt(0.2), 1.0, sqrt(1.8)) reside.
2. Information Loss from Global Temporal Mean Pooling:
   - Both QPSK and QAM16 have zero-mean four-quadrant symmetry.
   - Averaging 256 temporal tokens collapses multi-modal amplitude cluster distributions into a single centroid vector, obscuring the multi-ring structure of QAM16.
3. Model Overfitting:
   - 1.4M parameters with max_sequence_length=20000 embedding table and low regularization (dropout=0.1, zero weight decay) memorizes training noise rather than invariant constellation geometry.

--- TECHNICAL JUSTIFICATION FOR GNN ---
GNN Status: JUSTIFIED
- QPSK and QAM-16 are topologically distinct in (I, Q) space:
  - QPSK forms 4 clusters on 1 circle; all pairwise distances and transition magnitudes are symmetric and uniform.
  - QAM-16 forms 16 clusters across 3 concentric energy levels; node degrees in a k-NN/RBF graph naturally distinguish corner points (2 nearest neighbors), edge points (3 neighbors), and inner points (4 neighbors).
- Graph Construction:
  - Nodes: N=64 downsampled constellation tokens with features [I, Q, mag, diff_cos, diff_sin].
  - Edges: Pairwise Gaussian RBF kernel over 2D Euclidean distance in (I, Q) plane: A_ij = exp(-gamma * ||(I_i, Q_i) - (I_j, Q_j)||^2) combined with temporal band transitions (A_ij for |i-j| <= 1).
  - Degree-Normalized Laplacian: A_hat = D^{-1/2} (A + I) D^{-1/2}.
  - Message Passing: 2-layer Graph Convolution (GCN) implemented in pure PyTorch (zero external dependencies).
  - Graph Pooling: Dual Mean + Max pooling to capture both cluster centroid and extreme constellation state boundaries.

--- MULTI-BRANCH FUSION ARCHITECTURE ---
- Branch A (CNN): Multi-scale strided Conv1D (k=31,s=4 -> k=7,s=2 -> k=7,s=2) -> global pooling -> h_CNN (64-dim)
- Branch B (Transformer): 2-layer TransformerEncoder (d_model=64, nhead=4) over 256 tokens -> h_Trans (64-dim)
- Branch C (GNN): 2-layer Constellation GCN over 64 spatial nodes -> h_GNN (64-dim)
- Fusion Head: Concatenation [h_CNN || h_Trans || h_GNN] (192-dim) -> Linear(192, 64) -> BatchNorm1d(64) -> GELU -> Dropout(0.2) -> Linear(64, 5).
- Total Parameters: ~148,165 parameters (10x reduction from run_017's 1.4M parameters).

--- REGULARIZATION PLAN ---
- Weight Decay: 1e-4 via Adam / AdamW optimizer.
- Dropout: Increased from 0.1 to 0.2 across Transformer, GNN, and Fusion head.
- Batch Normalization: BatchNorm1d after CNN layers, GCN message-passing layers, and Fusion layer.
- Capacity Control: Compact positional embedding (256 tokens instead of 20,000 max sequence length table).

--- ABLATION EXPERIMENT PLAN ---

EXPERIMENT: RUN_021 PREPARATION — RMS POWER NORMALIZATION FIX

--- ROOT CAUSE & HYPOTHESIS ---
- Root Cause Identified: load_signal_raw_iq() previously used scale = float(np.max(mag)).
  Because 
p.max(mag) depends on arbitrary single-sample RRC filter edge overshoots and noise peaks (varying randomly from 1.0 to 18.3 across signals), it caused random 14x-18x scaling distortions of constellation radii across signals within the same class, destroying constellation radius consistency.
- Hypothesis: Replacing single-sample max-magnitude scaling with deterministic Root-Mean-Square (RMS) power normalization scale = sqrt(E[|x|^2]) anchors average signal power E[I^2+Q^2] to exactly 1.0, preserving consistent constellation geometry and amplitude distributions across the entire dataset.

--- EXACT NORMALIZATION CODE CHANGE ---
In load_signal_raw_iq() (ai/training/train.py) and predict.py:
OLD:
    scale = float(np.max(mag))
    if scale > 0:
        i = i / scale
        q = q / scale
        mag = mag / scale

NEW:
    scale = float(np.sqrt(np.mean(mag ** 2)))
    if scale > 1e-12 and np.isfinite(scale):
        i = i / scale
        q = q / scale
        mag = mag / scale

Safeguard added for scale <= 1e-12 or non-finite values.

--- REASON FOR EXPERIMENT ---
Isolate the normalization fix as a controlled ablation without altering any model architecture, layers, loss functions, tokenization, or dataset splits.
