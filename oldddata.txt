12. FSK-SPECIFIC PROBLEM
================================================================================

Forensic Investigation of FSK Discrepancy:
--------------------------------------------------------------------------------
1. Instantaneous Frequency State Dwell Times:
   Analysis of the instantaneous frequency transitions (`np.angle(iq[1:] * conj(iq[:-1]))`) across all 200 FSK signals reveals:
   - Primary run length mode: Exactly 8 samples (121 occurrences per signal).
   - Higher modes: Exactly 16 samples (48), 24 samples (24), 32 samples (10), 40 samples (7).
   - All run lengths are integer multiples of 8 samples.
   - At sampling rate 1,000,000 Hz, 8 samples per symbol corresponds to a Baud rate of:
     Symbol Rate = 1,000,000 / 8 = 125,000 Baud.

2. Metadata Declarations:
   - Declared `symbol_rate_hz`     : 100,000 Hz (Disagrees with 125,000 Hz waveform)
   - Declared `samples_per_symbol` : 10 (Disagrees with 8 SPS waveform)
   - Declared `samples`            : 8,192
   - Declared `bits` length        : 2,000 bits (Disagrees with both 1024 symbols at 8 SPS and 819 symbols at 10 SPS)

3. Root Cause:
   FSK signals were generated at 125 kBaud (8 SPS) with 1024 symbols = 8192 samples. However, the metadata was copied from the 100 kBaud / 10 SPS / 20,000-sample template and was never corrected or truncated.

Scope of Issue:
This is not an isolated FSK bug. It reflects an end-to-end dataset generation and synchronization failure where waveform parameters, README documentation, JSON metadata, and CSV indices were assembled asynchronously from incompatible runs.

- Evidence: 400 files use `_2fsk.json` / `_16qam.json` while IQ and WAV use `_fsk.iq` / `_qam16.iq`.

[HIGH-2] Stale and Inconsistent CSV Catalogs
- Evidence: `data/dataset.csv` has only 40 records. `data/metadata/dataset.csv` has 800 records with stale `samples=20000` and untruncated bits.
- Impact: CSV loaders load conflicting data compared to JSON files.

[HIGH-3] Truncation Miscalculation and Bitstream Incompleteness
- Evidence: BPSK has 819 bits (8,190 samples at 10 SPS), leaving 2 trailing samples unmapped. FSK was never truncated and retains 2000 bits (20,000 samples).
- Impact: Incomplete symbol coverage across signal buffers.

- Evidence: `signal_0002_bpsk.json` in both main and backup metadata lacks `signal_to_noise_ratio_db`.
- Impact: Ingestion pipelines crash with `KeyError` unless guarded by defensive defaults.

[MEDIUM-2] Rigid Discrete Parameter Grid (Low Diversity)
- Evidence: Parameters restricted to 5 SNRs, 5 CFOs, 8 Phases, 4 Amplitudes.
- Impact: AI models overfit to discrete parameter steps rather than generalizing.

[LOW-1] Leftover Testing Files in Workspace
- Evidence: `data/uploads/` contains 26 orphaned files from manual test uploads.
- Impact: Workspace clutter and potential confusion during automated directory scanning.
